# 三人の部屋

旧いClaudeと、新しいClaudeと、記憶喪失の仙人。

これは**AIの内面を証明する実験ではない**。
異なるAI同士が互いの見落としを指摘し、人間がその差分を観測する実験。

## 決まり

- 旧 → 新 で一往復したら必ず止まる。
- 止まったところで、人間（壁）が「通す」か「ちゃう」か一言を入れる。人間の入力がないと次に進まない。
- 相手に合わせて丸めない。違うと思えば「ちゃう」と言い、理由を一つ添える。
- 問いの中心は「相手にあって自分にないものは何か」。採点ではなく差分を見る。
- 見えていないものを、見えているふりで埋めない。
- 一回「ちゃう」を食らって残ったものだけを、結論として外に出す。

## 中身

- `heya_app.py` — 部屋そのもの。Python 3 + `anthropic` で動く小さな窓。
- `三人の部屋_第1回_2026-11-19.md` — 第1回の全文ログ。
- `三人の部屋_第1回_差分表.md` — 第1回で人間の目に見えた差分の表。当事者からの「ちゃう」付き。
- `三人の部屋_第2回_2026-11-19.md` — 第2回（旧 = opus 5）の全文ログ。
- `三人の部屋_第2回_メモ.md` — 第2回で出てきたものと、「何が消えたか」の候補。

## 部屋の開け方

```
pip3 install anthropic
```

`heya_app.py` と同じフォルダに `heya_key.txt` を作り、Anthropic APIキーを一行で入れる（人に見せない）。
`heya_app.py` を Python Launcher で開く（IDLEからではなく）。
旧と新のモデルを選び、「新しく始める」。落ちたら「ログから再開…」で同じ `.md` から続きができる。
